# Provenance and operational adaptation

The native Dense model, RoleAdamW, original BDT transform, CMS1 geometry, and constants have exact byte hashes in UPSTREAM_MANIFEST.json. The complete original GCT1 runtime/policy/train/analysis sources and the original OCB1 model/snapshot utilities remain in frozen/. These came from the user's prior packages and hash-verified archived backend, not a rewritten substitute.

`gct_train_adapter.py` differs from the archived train file only in docstring, progress label, and scientific-scope text. Tensor expressions, schedules and control flow are unchanged. AST comparison (ignoring string metadata) and actual-backend control executions test this adaptation. `core.engine` binds that code to a new protocol, output root, candidate seed cohort and transactional I/O; scientific policy arithmetic stays unchanged.

`candidate/diagnostics_lite.py` is generated by the approved builder from tempering_reference.py hash d1bd72d9ccd18019aea83551b838d5915f727a0a7b6a0a2fd1006fb1c47969f1. Its hash is ef3616d538a806cd01fe8941742f62beb2167e53c87b74f10fbd6f75d50c4ab5. It is used only by BCO1, never GCT2.

`candidate/profiled_reference.py` adds record_function regions to a separate reference copy. Removing only those wrappers/import recovers the identical original AST. The profile is additionally checked against uninstrumented numerical execution before accepting attribution.

The bundled cms_protocol.py is the existing constants-only copy from the practical-followup release. It retains the original CMS1 geometry thresholds and VERSION used to derive permutations. Its header identifies original full-protocol hash e941b4274b27b1642e9467fdafe144fa79c378c199d2b5d35358fb7428261b7c. It is not represented as byte-identical to that full original file.

Original protocol documents and machine specifications in design/ are unchanged. Their design-stage status fields are historical document metadata; runtime registration, cohort seals and scheduler status are separate evidence. The extra GCT2 gate parent-reference prefix is an engineering check, not additional scientific training or a changed treatment.

SOURCE_MANIFEST.json covers all release code, bundled scientific sources, protocols and operational files. All new study records identify its digest. CPU receipts, generated after freezing the release, are outside the installed source tree to avoid self-referential or mutable manifests.
